# Enthalpio Desktop

ПК-версия Enthalpio — экосистема климатической отрасли.

## Скачать

**[Enthalpio-Desktop-1.0.0.zip](https://github.com/enthalpio/enthalpio-desktop/releases/download/v1.0.0/Enthalpio-Desktop-1.0.0.zip)**

## Что внутри

- Расчёты холода (М1–М3).
- Вентиляция (М4).
- Кондиционирование (М5).
- PDF-экспорт.
- Пошаговый ввод (как AutoCAD).

## Системные требования

- Windows 10+ (x64).
- ~50 МБ свободного места.
